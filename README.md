# TORNADO — концепт главной (FL.ru №5528349)

Живой статический концепт главной страницы интернет-магазина пневмооборудования TORNADO
по брифу «Сталь и витрина»: светлая индустриальная витрина, холодный фон, стальные фото,
синий акцент, плотная сетка товаров и крупные цифры. Без фреймворков, без CDN-скриптов,
шрифты — Unbounded (заголовки) + Manrope (текст) через Google Fonts с кириллицей.

Файлы: `index.html`, `assets/style.css`, `assets/app.js`, `assets/img/*` (фото генерируются
параллельно, файла может не быть — вёрстка не схлопывается: `aspect-ratio` + подложка `--soft`).

## Секции (8)

1. Шапка: тонкая верхняя полоса + sticky-шапка (логотип-SVG, меню, ghost-кнопка звонка, корзина).
2. Hero: H1, подзаголовок, две кнопки, способ доставки, фото `hero.jpg` (5/6) с плашкой
   «В наличии · Москва», строка из 4 фактов, 3 «быстрых» плашки.
3. Категории: 5 плиток (две крупные + три квадратные), счётчики позиций.
4. Популярное у мастеров: чипы-фильтры и 4 карточки товара с ценами, бейджами и корзиной.
5. Подбор за 3 шага: шаги 01/02/03 и три плитки-сценария.
6. Что входит в заказ (4 пункта) + таблица-сравнение «Обычный магазин / У нас», 4 строки.
7. Полоса сервисов: 4 пункта с иконками.
8. О нас (фото `lifestyle.jpg` + 3 факта) и отзывы (3 карточки с плашкой «демо-текст»),
   футер: контакты, меню, сноска про гарантию, плашка «Концепт-демо для FL.ru №5528349».

## Палитры

Три набора токенов из брифа на `[data-theme="b"|"c"|"a"]` у `<html>`:
B «Сталь» (по умолчанию, синий/светлый), C «Графит» (янтарный/тёмный), A «Тёплый цех»
(терракота/тёплый). Переключатель — фиксированная пилюля «Стиль: Сталь ▾» внизу слева:
раскрывает три кнопки, пишет `data-theme` и `localStorage['tornado-style']`, состояние кнопок —
`aria-pressed`, у самой пилюли `aria-expanded`. Выбор переживает перезагрузку.

## Интерактив (ванильный JS)

- Мобильное меню (бургер, `aria-expanded`, блокировка скролла, Escape, закрытие по ссылке).
- Панель палитр (закрытие по клику вне и по Escape).
- Корзина: счётчик с `aria-live="polite"`, тост «Добавлено в корзину», лёгкая анимация счётчика.
- Чипы-фильтры каталога (`data-cat` на чипах и карточках), пустое состояние с кнопкой сброса.
- Плавные якоря с учётом высоты sticky-шапки; при `prefers-reduced-motion` — без анимации.
- Тень шапки при скролле.

## Доступность

Один `<h1>`, все `img` с `alt` и `width/height`, skip-link, видимый `:focus-visible`,
`prefers-reduced-motion`, `aria-live` на счётчике и тосте, семантическая таблица с
`scope`/`caption`, на мобиле таблица превращается в карточки с подписями из `data-label`.

## Проверки

- `node --check assets/app.js` — без ошибок.
- `python check_demo.py --dir ...` — блокирующих ошибок нет; предупреждения — только
  про файлы фото, которые генерируются параллельно.
- Скриншоты 1440/390 через CDP в этой сессии снять нельзя: headless Chrome не стартует
  в песочнице субагента (запрет на именованные каналы). Адаптив проверен статически
  (ширины, переносы, `nowrap`-места); финальную приёмку скриншотами делает лид — `shot.py`.
